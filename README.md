# UIL Public Product Overview

This repository contains the sanitized public product overview for UIL. It is intentionally separate from the private implementation repository and contains no source code, build specifications, internal API contracts, deployment details, browser artifacts, diagnostics, credentials, or private links.

The site explains what the product is intended to do, how it works at a high level, its operating modes, safety boundaries, and public capability status.

## Public site

The GitHub Pages site is generated from `index.html` and is designed for humans and AI tools that need a product-level understanding without access to engineering details.

## Files

- `index.html` — public overview, architecture, safety, capability status, and FAQ.
- `capabilities.json` — sanitized machine-readable product summary.
- `SECURITY.md` — public reporting boundary; no private runtime or source details are included here.

## Deliberate exclusions

This repository does not contain private source, internal file paths, implementation specifications, provider credentials, extension packages, runtime URLs, diagnostic feeds, API schemas, selectors, deployment identifiers, or unreleased roadmap information.
